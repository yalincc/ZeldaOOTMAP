## 2. 单分支 `master` 方案（2026-11-26 收敛）

为避免 `master` + `deploy` 双分支搬运与漏同步问题，仓库已收敛为**单分支 `master`**：

- `app/assets`（约 29 MB）已取消 `.gitignore` 忽略，直接随 `master` 入库。
- `deploy` 分支（2026-11-24 上线时为“含 assets 的构建分支”创建）已于 2026-11-26 双端删除，本地遗留 worktree 一并移除。
- **踩坑记录**：11-26 首次“收敛”只改了仓库、没改 EdgeOne 控制台，生产分支仍挂在 `deploy`，导致 `master` 两天没上线（线上还是 `style.css?v=4`、新图标 404）。判据：线上 `?v=` 与哪条分支的 `app/index.html` 一致，就是在用哪条分支构建。**改仓库分支后必须同步改控制台生产分支。**

## 2.1 页面边界（硬约束）

- EdgeOne 构建根目录 `./`、**输出目录 `app`**：只有 `app/` 下的文件会上线。
- 所有站内页面（含攻略页 `app/guide.html`）必须在 `app/` 内，相对链接不得出现 `../docs/` 这类越界路径，否则线上一律 404（本地 `verify_all.py` 查不出来，因为文件在本地是存在的）。
- `tools/`、`data/`、`docs/`、`report/`、`归档/` 只入库、不上线。

## 3. 日常更新流程

> 本机 `git` 未加入 PATH，可直接用 `& 'C:\Program Files\Git\cmd\git.exe'`，或把 Git 的 `cmd` 目录加入 PATH。

### 3.1 改源码并验收后推送

```powershell
cd E:\WorkSpace\ZeldaOOTMAP
python tools\verify_all.py
git status
git add -A
git commit -m "feat: ..."
git push origin master
git push gitee master
```

### 3.2 等 EdgeOne 自动构建

推送 `master` 后，EdgeOne 会自动拉取 Gitee 的 `master` 并构建。正常约 30–40 秒。

检查点：

- 状态：成功
- 分支：`master`
- 提交：刚推的短哈希
- 输出目录：`app`

### 3.3 线上验收

```powershell
Invoke-WebRequest -Uri 'https://oot.yalin.site/' -Method Head
python tools\verify_all.py
```

人工检查：

- 首屏默认进区域图，底图与图标正常显示。
- 区域图 / 拓扑图 / 全图三档可切换；缩放换层正常。
- 手机 390×844：侧栏抽屉、底部详情卡、双指缩放、全图聚焦正常。
- 抽查 `assets/ui/basemap_2400.webp`、`assets/maps/field/*.webp`、`js/app.js`、`guide.html` 均返回 200，无 404。
- 首页 `?v=` 与本机 `app/index.html` 一致（不一致=线上跑的是旧构建）。

## 4. 域名与证书

- DNSPod 已添加：
  - `oot` → CNAME `oot.yalin.site.pages.dnsoe6.com`（TTL 600）
  - `edgeonereclaim.oot` → TXT 归属验证（EdgeOne 添加域名时生成，保留）
- EdgeOne 域名管理显示“已生效”后，HTTPS 配置选 **申请免费证书 → 自动验证**。
- 证书首次签发需要几分钟；签发完成前 HTTPS 可能短暂不可用，HTTP 可先访问。
- 证书由 EdgeOne 自动续签，不需要手工上传。

## 5. 回滚

优先在 EdgeOne 控制台“构建部署”历史里选择上一个成功部署，回滚发布。

只有在需要回退源码时，在 `master` 分支回退并重新推送：

```powershell
cd E:\WorkSpace\ZeldaOOTMAP
git log --oneline
git revert <问题提交>
git push origin master
git push gitee master
```

## 6. 禁止事项

- 不要手工修改 EdgeOne 构建产物；所有线上内容必须来自 `master` 分支。
- 不要在未跑 `verify_all.py`、未看 PC/手机两档效果前推 `master`。
- `commit / push / tag / Release` 仍按项目规则逐次确认；EdgeOne 自动部署不等于“发版”。
