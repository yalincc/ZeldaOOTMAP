# Quest Data Build Plan（进行中）

> 门1 已确认：2026-11-26 · 本文件不带版本号，完成后标「完成」移归档。

## 范围

以 **Switch 2 重制版（2026）** 为准，原版差异单独标注：

1. 时光之线 13 条主任务（含 3 条灵石子任务、5 条神殿子任务）
2. 官方支线 7 条
3. 经典长链 / 小游戏 / 收集链（大鼓隆之剑交易、面具交易、丹佩挖坟、钓鱼、赛马、保龄球、大妖精、瓶子等）
4. 12 座迷宫 / 神殿流程，挂到对应主任务

目标约 60–80 条，每条写完整流程，不做只有标题的空条目。

## 数据源与口径

优先级：重制版官方任务日志（Game8 / Gamerant / Zelda Central）> 中文攻略（游民星空 / 娱乐计程车 / 18183）> Zelda Wiki 原版资料（仅补经典长链）。

- 每条带 `sources` 数组（具体 URL），冲突以重制版为准并记录差异
- 不猜坐标：只用现有区域名 + 已有点位 ID 做挂接；缺失字段留空不编
- 本轮只出底表，不动 `app/`、不接网页、不 push

## 产出

`data/quests/`：

| 文件 | 内容 |
|---|---|
| `quests_main.json` | 时光之线 13 条 + 子任务层级 |
| `quests_side.json` | 官方支线 + 扩展支线 / 长链 |
| `quests_dungeon.json` | 12 迷宫 / 神殿流程 |
| `README.md` | 字段说明与使用边界（中文正文） |
| `sources.md` | 来源清单、版本口径、差异记录 |

字段：`key / name_zh / name_en / category / era / npc_zh / start_zh / steps / deliver_zh / reward_zh / requires / unlocks / region / pin_ids / sources / status`。

## 步骤

1. 联网抓主任务、支线、迷宫与长链资料，整理成结构化条目
2. 生成五份底表文件
3. 校验（条目数、字段完整率、来源覆盖、与 243 清单 / 485 点位交叉引用）
4. 交老大审阅 → 停下；接入网页另立方案

## 验收

- 60–80 条；主任务 13 条层级完整；支线 7 条字段齐全；迷宫 12 条可挂主线
- 每条至少 1 个来源 URL；抽 5 条人工核对无事实性错误
- `app/` 零改动，`python tools/verify_all.py` 仍通过
