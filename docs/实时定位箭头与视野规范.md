## 1. 官方箭头图标规范

- **唯一资产**：使用 RomFS 原图 `app/assets/ui/MapIconPlayer_01.png`（`128×128 RGBA`，内含官方 `47×54` 红底奶油描边箭头）。
- **严禁裁剪原图留白**：保持 `128×128` 原始透明边距与中心锚点，不走「84% 居中裁剪」管线，确保旋转中心与箭头重心一致、且与游戏内小地图比例同源。
- **阴影与抗锯齿**：`filter: drop-shadow(0 2px 4px rgba(0, 0, 0, .65))`，`object-fit: contain`，禁止拉伸。

## 2. 相机视野扇形（FOV Cone）规范

对照实机小地图效果，视野扇形必须满足**「两侧锐边 + 径向消隐到全透明」**：

| 参数 | 规范值 | 说明 |
|---|---|---|
| **水平张角** | **80°**（半角 40°） | 贴合 3D 第三人称相机水平 FOV（75°–85°） |
| **SVG 几何** | `viewBox="0 0 180 180"`<br>`M90 90 L35 24 A86 86 0 0 1 145 24 Z` | 圆心 `(90, 90)`，弧半径 `86` |
| **两侧边缘** | **锐边不羽化** | 禁用横向模糊或角度羽化（避免 `conic-gradient` 边缘发虚） |
| **渐变方式** | **以 `(90, 90)` 为圆心的 `radialGradient`** | 禁用垂直 `linearGradient`（否则左右斜角外缘会残留弧线） |
| **渐变半径** | **`r="84"`**（严格 `<` 扇形半径 `86`） | 保证全角度在到达外弧前已完全衰减为 `opacity: 0` |
| **色标停靠点** | `0%` `#fffbe6` `0.78` → `45%` `#fff8d6` `0.42` → `80%` `#fff8d6` `0.10` → `100%` `0` | 暖白奶油光感，不遮挡底图路径与点位 |

## 3. PC 与手机双端尺寸基线

定位层 `.navi-link-dot` 挂在 `#naviLayer` 内，统一应用 `transform: translate(-50%, -50%) scale(var(--region-inv, 1))` 反向缩放，确保地图放大到 `200%` 时标记仍维持恒定屏幕尺寸：

| 断点 | 箭头容器 `.navi-arrow` / `.navi-arrow-img` | 视野扇形 `.navi-fov` |
|---|---|---|
| **PC 端（`> 900px`）** | `64px × 64px`（可见箭头约 `24×27px`） | `168px × 168px` |
| **手机端（`≤ 900px`）** | `46px × 46px`（可见箭头约 `17×19px`） | `120px × 120px` |

## 4. 角度与数据口径

后端 `/pos` 必须将**角色朝向**与**相机视野方向**解耦输出，两者独立旋转：

- **顺时针角度定义**：`0°` = 正北（地图上方，世界 `-Z`）、`90°` = 正东（地图右方，世界 `+X`），范围 `[0, 360)`。
- **`facing`（箭头旋转）**：取林克变换矩阵第 3 列前向向量 `(m02, m22)` → `atan2(m02, -m22)`。
- **`camFacing`（视野扇形旋转）**：取相机眼位 `(camX, camZ)` 指向林克 `(linkX, linkZ)` 的水平向量 → `atan2(linkX - camX, -(linkZ - camZ))`；无相机数据时回退为 `facing`。

## 5. 60fps 平滑跟随与零空耗约定

- **采样与轮询**：后端 `20Hz`（50ms），前端链式 `setTimeout` `12.5Hz`（80ms，带 `?t=` 防缓存，不重叠请求）。
- **渲染插值**：`requestAnimationFrame` 每帧以 `alpha = 0.28` 对 `(u, v)` 与角度（最短角差 `((target - cur + 540) % 360) - 180`）做平滑插值，并同步驱动 `centerRegionUV`。
- **静止收敛防重绘**：当 `|Δu| < 0.002`、`|Δv| < 0.002`、`|\Delta \text{facing}| < 0.05^\circ`、`|\Delta \text{camFacing}| < 0.05^\circ` 时跳过 DOM 写入与相机更新，保持静止零开销。
- **跨区瞬移**：检测到 `scene` 切换区域时，立即将当前插值坐标对齐新区域目标点，禁止跨图飞线插值。
