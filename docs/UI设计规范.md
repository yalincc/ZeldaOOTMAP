# ZeldaOOTMAP · UI 设计规范（现状基线）

> 状态：草案（随「形态 C 双模式」实施后会更新一版）
> 用途：防止改样式时无意破坏已验收的视觉基线。**色值/尺寸/断点属基线，改动先说明影响。**

## 1. 主题与色板

暗金 / 羊皮纸风，取自游戏内地图与 UI 图集。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg-deep` | `#160d08` | 页面底色 |
| `--bg-board` | `#20140c` | 画布底色 |
| `--gold` | `#eab308` | 主强调色（标题、选中、进度） |
| `--gold-glow` | `rgba(234,179,8,.4)` | 光晕 |
| `--text-main` | `#f5eedb` | 正文 |
| `--text-dim` | `#b8ad96` | 次级文字 |
| `--text-mute` | `#7d725d` | 弱提示 / 分隔 |
| `--cell-bg-grad` | `linear-gradient(145deg,#8a5f39,#6f4728)` | 区域卡片底 |
| `--cell-border` | `#4a2f1a` | 区域卡片描边 |
| `--dungeon-border` | `#881337` | 迷宫卡片描边（暗红） |

分类徽章色：心碎 `#ef4444`、蜘蛛 `#f59e0b`、妖精 `#c084fc`、大魄 `#818cf8`、洞穴 `#d97706`、八卦石 `#94a3b8`、商店 `#f97316`、小游戏 `#ec4899`。
新增分类必须同时给 `badge` 色，否则侧栏色点缺失。

## 2. 字体与字号

- 字族：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
- 字号阶梯：**10 / 11 / 12 / 12.5 / 13 / 13.5 / 14 / 15 / 16 px**
  - 顶部品牌 16 px，大分类标题（大地图 / 迷宫）16 px，收缩栏标题（本区图标 / 全收集进度）15 px，列表项（区域 / 图标）13.5 px，计数与辅助标签 12~12.5 px。
  - 不新增 17 px 以上字号（除详情卡标题）。
- 数字对齐：`tabular-nums`（`font-variant-numeric: tabular-nums`），避免侧栏与正文混用 `monospace` 导致视觉割裂；仅坐标等技术字段使用 `monospace`。

## 3. 布局基线

| 元素 | 尺寸 |
|---|---|
| 顶栏 `--topbar-h` | 56 px |
| 左侧栏 `--sidebar-w` | 320 px（折叠 `margin-left: -320px`） |
| 区域卡片 | 400~560 px 宽（按区域真实宽高比） |
| 详情卡 | 336 px，距右/上 20 px，圆角 12 px，`blur(12px)` |
| 缩放控件 | 按钮 38×36 px，右下 18/24 px |
| 圆角 | 卡片 12 px、按钮 8~10 px、标签 4~6 px |

## 4. 图标与标点

- 点位图标用官方 `MapIcon*.png`（128×128 透明 PNG），**不自行绘制替代**。
- 图标在画布上按 `--zoom-inv = 1/zoom` 反向缩放，保持屏幕物理尺寸恒定；缩放时不得出现糊边（用 `image-rendering: auto` + 原始 128px 源）。
- 区域/迷宫卡片内的 pin 坐标是底图百分比（`left/top: x%`），底图 `object-fit: contain`，pin 层必须按实际渲染矩形对齐（`getNodeImageRect`）。

## 5. 响应式断点（第一版）

| 断点 | 行为 |
|---|---|
| `≤900 px` | 左侧栏改为抽屉（默认收起，汉堡键滑出，宽 `min(86vw,320px)`）；顶栏允许换行、进度条压缩；详情卡改底部抽屉（左右 8 px、底部 8 px、最大高 45vh） |
| `≤600 px` | 品牌副标题隐藏；缩放控件缩小并贴右下；跳转芯片单行横滑 |

- 触控：单指拖拽平移、双指捏合缩放（已有 `touch` 处理），**不得用双击缩放与页面滚动冲突**。
- 所有可点元素命中区 ≥ 32 px。

## 6. 交互约定

- **详情卡（TOTKmap 对齐 · 7 行槽位网格）**：
  - 第 1 行仅放分类徽标 + 右上 `‹ › ×`（不显示数字计次）；第 2 行金底黑字 `#序号` 徽标 + `16px` 标题；正文采用固定左列 `44px` 标签（`12.5px` 暗金）+ 右列正文（`13px` 暖白、`line-height: 1.65`）统一对齐网格，关联点位以下划线内联链接直嵌正文（已完成态压暗加删除线）；第 7 行为整宽 `40px` 金色主操作按钮（完成后转翠绿态）。
  - **多信息槽位 ID 筛选（`CARD_SCHEMA`）**：标准槽位 `req / next / loc / reward / tip / coord`，按分类模板决定展示顺序与标签（空槽位自动隐藏；`coord` 仅校准模式显示）。
- **重叠图标与聚合主卡**：主点（`subPins`）在区域/拓扑图默认折叠同址可见子点（`hostPinId`），右上角显示暖金数字角标；点开后卡片第 2 行下方展示可换行的极简底线 Tab，与奖励槽内联链接联动高亮（同宿主内分类唯一时自动省去括号出处仅保留容量数字）；关闭主点分类筛选时，子点自动独立渲染。
- **卡片拖动与位置记忆**：PC 端（`> 900px`）支持通过 `.dc-head` 六点抓手及标题空白区自由拖动（防文本蓝选、排除按钮/链接/Tab），拖动后切 Tab、标记或 `‹ ›` 翻页保持位置，关闭卡片后再开新点恢复自动避让定位；移动端保持底部固定不拖。
- **同类遍历器**：详情卡头部右侧提供 `‹ / ›` 按钮（悬停显示页码提示，配键盘 `← / →` 快捷键），跨区/跨时代顺序历遍同类点位（开启「隐藏已收集」时自动跳过已勾项）。
- 校准模式：顶栏「校准点位」进入，顶部提示条出现；拖拽图标改坐标，退出时导出/下载。
- 提示条、抽屉等临时浮层必须真正受 `[hidden]` 控制（CSS 里 `.xxx[hidden]{display:none}` 兜底）。
- 动效：0.12~0.25 s，`cubic-bezier(.4,0,.2,1)`；不做循环闪烁（除校准目标微光）。

## 7. 禁止项

- 禁止引入紫色/靛蓝主色（与暗金主题冲突）。
- 禁止把分类色写死在 JS 里另建一套（色值只认 `pins_data.js` 的 `badge`）。
- 禁止未经确认改 `--sidebar-w` / `--topbar-h` / 断点（会连带影响校准与卡片定位）。
- 禁止用截图当底图（底图只认官方解码产物）。
- **禁止在 `style.css` 末尾追加同名覆盖块**：改 `.cat-item` / `.region-item` 等组件样式时先全局搜同名选择器，避免前改后被旧规则覆盖（2026-11-26 踩坑）。
- **侧栏磨砂与缓存**：`.sidebar` 与 `.side-foot` 保持半透明磨砂底色；修改 `style.css` / `app.js` 后须同步递增 `index.html` 的 `?v=` 查询参数。
- **实时定位箭头与视野**：见专项规范 `docs/实时定位箭头与视野规范.md`（官方原图不裁剪、80° 锐边径向消隐扇形、PC/手机双端尺寸基线）。
