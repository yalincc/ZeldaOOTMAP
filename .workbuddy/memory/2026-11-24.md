## ★ 存档真值验证完成（13:17，阶段 0 收尾）

- 老大原地存档 slot_01 → 坐标仍 (-12.058,103.665,10.319)（人没动）。按真值排序 105 条结构缓冲：**4 个副本的 [0] 帧 (-10.047,103.961,10.875) 距真值均 2.11m**（最近），地址 `0x1010676FAE90/6FE190/84ACF0/84D990` = 林克真身轨迹镜像。
- **★ 结构最终定性**：不是环形缓冲！是**定长历史轨迹数组**（32 组）：[0..21] 一组时代(童年)、[22..31] 另一组(成年)、[32+] marker=0 结束。**[0]=当前时代最新位置**。之前 watch 跳变 = 多副本更新时刻不同 + monitor.py 40s 采样证实各副本首帧在 6~7 个固定值轮转（假象）。
- **最终读法**：marker=-0.4 结构指纹定位主缓冲 → 读 [0] 帧 → 多副本取众数抗跳变 → 按时代选 [0..21] 或 [22..31] 段 → 基址后期做静态链固定。
- 新增工具：`tools/ootnavi/monitor.py`（持续采样多缓冲找活动）、`structscan.py`（结构指纹扫描）。结论写入方案 §8.7。**阶段 0 达成：addr + 读法已确认，可进阶段 1 定位核心。**
