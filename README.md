# 塞尔达传说：时之笛 · 全能互动地图

《The Legend of Zelda: Ocarina of Time》Switch 2 重制版的本地离线互动地图 + 100% 全收集攻略。
纯静态网页、零后端、零依赖，双击即开；点位、底图与图标全部取自官方 romfs。

当前版本：**V0.1.0（内测）**

---

## 功能

**地图**
- **出入口拓扑导图**：31 个区域/迷宫节点、33 条真实连通线路，一眼看清「从哪进、从哪出、走哪条近道」；节点底图为游戏内区域地图，支持童年/成年双底图切换。
- **362 个官方点位 / 12 大类**：心之碎片 36、黄金骷髅蜘蛛 100、迷宫宝箱 100、八卦石 37、秘密洞穴 36、迷你游戏 15、商店 12、大怨灵 10、大妖精之泉 6、关键道具 5、时之歌传送点 4、迷宫入口 1。全部带游戏世界坐标。
- **时代与昼夜筛选**：童年 / 成年 / 全部；白天限定 / 夜晚限定。
- **分类图层**：12 类独立开关，支持全选 / 清空，分类旁实时显示当前视图数量。
- **搜索**：按点位名、物品、地点实时搜索，点结果一键聚焦。
- **详情卡**：编号、分类、时代、昼夜、前置要求、攻略说明、世界坐标，可标记「已收集」。
- **进度追踪**：完成数与百分比实时更新，进度保存在浏览器本地；支持「隐藏已收集」查漏。
- **点位校准模式**：可拖拽图标对齐地图地标，一键复制坐标或下载新的点位文件。
- **中英双语**：一键切换。
- **URL 深链**：`?node=KokiriForest` 直达区域，`?pin=HP-001` 直达点位。

**100% 全收集攻略（`docs/oot100-guide.html`）**
- **243 项 / 14 大类**：心之碎片、Boss 心之容器、黄金骷髅蜘蛛、歌曲、精灵石/勋章、战斗道具、装备、容量升级、瓶子、大妖精奖励、面具、大魄、猫头鹰像、其他奖励。
- **四视图**：主线导图（时间主干 → 地点枝 → 任务与收集）、剧情时间线（12 阶段）、任务线（6 条）、全部分类。
- **地点枝可展开**：逐条显示该地点此时能做的任务/收集，带条件与做法，可勾选。
- **位置图**：97 条已配对条目显示所在区域地图与坐标点。
- **筛选与进度**：地区、时期、昼夜、搜索；勾选进度与地图页各自独立保存，可导出 txt。

**多端**
- PC 与手机均可使用：窄屏侧栏自动收起为抽屉、详情卡变底部面板、支持触控拖拽与双指缩放。

## 启动

纯静态，无需安装与构建：

- **直接打开**：双击 `app/index.html`。
- **本地服务**（推荐，避免部分浏览器限制本地文件）：
  ```bash
  cd app
  python -m http.server 8080
  # 浏览器访问 http://127.0.0.1:8080
  ```
